# 成员 6：成绩与成绩单

## 你负责什么

你负责教师为已结束课程录入成绩，以及学生查看自己的成绩单、修读学分、获得学分和 GPA。成绩合法值为 A、B、C、D、F、I；空值表示还未录入，不等于不及格。

## 现场演示（60 秒）

1. 教师进入“成绩管理”，默认查看 2026-SPRING 已结束课程。
2. 打开 CS100 成绩册，把张同学成绩从 A 改为 B 并保存。
3. 切换学生账号进入“我的成绩单”。
4. 指出 B 对应 3.00 GPA，3 学分计入已获得学分。
5. 说明 OPEN 状态教学班不能录成绩，名单外学生也不能录。

## 核心代码块怎么讲

```java
if (offering.getStatus() != OfferingStatus.CLOSED) {
    throw new IllegalStateException("只能为已经结束的教学班录入成绩");
}
if (!VALID_GRADES.contains(normalized)) {
    throw new IllegalArgumentException("成绩只能是 A、B、C、D、F 或 I");
}
```

背法：先保证课程已经结束，再检查成绩字母；这样避免教师在选课期提前录成绩，也避免脏数据。

```java
private static final Map<String, Integer> GRADE_POINTS = Map.of(
    "A", 4, "B", 3, "C", 2, "D", 1, "F", 0);
BigDecimal gpa = gpaCredits == 0 ? BigDecimal.ZERO
    : BigDecimal.valueOf(weightedPoints)
        .divide(BigDecimal.valueOf(gpaCredits), 2, RoundingMode.HALF_UP);
```

背法：GPA 是“每门课程学分 × 绩点”的总和除以参与 GPA 的总学分，保留两位；I 暂缓成绩不参与计算。

## 60 秒背诵稿

> 我负责成绩与成绩单模块。教师只能操作自己任教且状态为 CLOSED 的教学班，并且学生必须真实出现在该班 ENROLLED 名单中。成绩只允许 A、B、C、D、F、I，空值表示尚未录入。学生成绩单不接受外部 studentId，而是从当前账号取得本人 ID，防止查看他人成绩。GPA 使用学分加权算法，A 到 F 对应 4 到 0，I 不参与 GPA；A 到 D 计入已获得学分，F 不计。该模块也向选课模块提供先修课是否通过的历史成绩判断。

## 必背术语

- **Grade Point**：字母成绩对应的绩点。
- **加权 GPA**：按课程学分加权平均，而不是每门课简单平均。
- **I / Incomplete**：暂缓成绩，不等于 F。
- **成绩单 Report Card**：学生本人可见的正式成绩汇总。
- **历史成绩**：用于成绩展示，也用于先修课校验。
- **名单约束**：只有真正录取到教学班的学生才能被录成绩。

## 老师追问

**问：为什么 I 不参与 GPA？**

答：I 表示成绩尚未完成，不应暂时按 0 分拉低平均绩点。

**问：F 计不计修读学分？**

答：计入 attemptedCredits 和 GPA 分母，但不计 earnedCredits。

**问：学生如何防止查看别人的成绩？**

答：接口没有 studentId 参数，Service 使用登录账号关联的学生 ID 查询。

**问：教师输入小写 b 怎么办？**

答：Service 会 `trim` 并转大写再校验，最终统一保存为 B。

**问：空成绩为什么不直接删除？**

答：课程要求允许空成绩。当前实现保留既有成绩或保持未录入状态，避免误操作把正式成绩清除。

## 及格重点

背熟“仅 CLOSED、仅本人任课、仅名单学生、A-F/I、学分加权 GPA”五点即可。
