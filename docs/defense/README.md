## 统一术语

- **Controller**：接收 HTTP 请求，检查参数和角色，调用 Service。
- **Service**：放业务规则和事务，是答辩最应该讲的部分。
- **Repository**：通过 Spring Data JPA 读写数据库。
- **Entity**：数据库表对应的 Java 对象。
- **DTO / View**：接口接收或返回的数据结构，避免把数据库实体直接暴露给前端。
- **事务**：一组数据库操作要么全部成功，要么全部回滚。
- **模块化单体**：只有一个后端进程，但代码按业务包隔离；不是微服务。

## 所有人统一开场

> 我们采用 Vue 3、Spring Boot 和 MySQL/H2，实现了模块化单体。七名成员分别负责七个纵向业务模块，每个模块都包含页面、接口、业务规则、数据访问和集成测试。这样部署简单，又能保证分工边界清晰。

## 不要说错的三件事

1. 不要说“我们用了微服务”。本项目是模块化单体。
2. 不要说“前端隐藏按钮就安全”。真正的权限由 Spring Security 和 `@PreAuthorize` 在后端执行。
3. 不要说“已经连接真实 DEC VAX/Ingres 和计费平台”。课程环境使用明确标注的只读目录适配模拟器和计费状态机。
