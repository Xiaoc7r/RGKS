# 成员 3：课程目录与教学班

## 你负责什么

你负责把课程、先修课、学分、学费和每学期教学班整理成统一的只读接口。题目中的旧 Ingres/DEC VAX 在课程环境无法真实接入，所以项目用明确标注的只读适配模拟器保留系统边界，而不是假装连接了真实主机。

## 先分清两个概念

- **Course 课程**：稳定的课程定义，例如 CS201 Java 程序设计、3 学分、先修 CS100。
- **CourseOffering 教学班**：某学期实际开出的班，例如 2026-FALL、周一 1–2 节、容量 10、由李老师任教。

一门课程可以在不同学期有多个教学班。容量、教师和时间属于教学班，不属于课程定义。

## 现场演示（60 秒）

1. 任意角色进入“课程目录”。
2. 指出页面顶部显示 `LEGACY_CATALOG_OPEN_SQL_SIMULATOR`、只读为“是”、预算 10 秒。
3. 找到 CS201，说明它的先修课是 CS100。
4. 指出同一行还聚合了教师、时间、容量、已选人数和余量。
5. 强调后端只暴露 GET，没有新增、修改、删除目录的接口。

## 核心代码块怎么讲

```java
long enrolled = scheduleItems.countEnrolledByOfferingId(offering.getId());
Course prerequisite = course.getPrerequisiteCourseId() == null
    ? null : courseMap.get(course.getPrerequisiteCourseId());
return new CatalogController.OfferingView(
    offering.getId(), course.getId(), course.getCode(), course.getName(),
    course.getDepartment(), course.getCredits(),
    prerequisite == null ? null : prerequisite.getCode(), course.getTuition(),
    professor == null ? "待定" : professor.getName(),
    offering.getSemester(), offering.getDayOfWeek(),
    offering.getStartPeriod(), offering.getEndPeriod(),
    offering.getCapacity(), enrolled,
    Math.max(0, offering.getCapacity() - enrolled), offering.getStatus());
```

背法：目录页不是简单查一张表，而是把课程、教师、选课统计聚合成前端直接使用的只读 View；余量等于容量减已录取人数，并用 `Math.max` 防止异常数据出现负数。

## 60 秒背诵稿

> 我负责课程目录与教学班模块。我们把 Course 和 CourseOffering 分开建模：Course 保存课程编号、名称、学分、先修课和学费，CourseOffering 保存某学期的教师、上课时间、容量、最低人数和状态。`CatalogService` 读取课程、教师和已录取人数，组装成只读 DTO 返回页面。题目要求目录来自旧 Ingres/DEC VAX，但课程环境没有真实旧系统，所以我们实现了只读适配模拟器，并通过 status 接口明确显示来源、只读属性和 10 秒响应预算。整个 catalog 模块只有 GET 接口，保证新系统不会修改旧目录。

## 必背术语

- **遗留系统 Legacy System**：仍在使用但技术较旧的已有系统。
- **适配器 Adapter**：把外部数据转换成当前系统统一模型。
- **只读边界**：允许查询，不允许写回。
- **聚合 DTO**：组合多个实体的数据，专供接口展示。
- **先修课**：选某课程前必须已经通过的课程。
- **教学班容量**：单个开课班允许录取的最大人数，本项目默认 10。

## 老师追问

**问：为什么不真的安装 Ingres？**

答：题目重点是软件设计和集成边界。真实主机不可获得，因此用适配器模拟稳定接口，同时明确记录这是课程替代实现，没有伪造连接结果。

**问：为什么不把教师姓名直接存在教学班表？**

答：教学班保存 professorId，姓名来自教师档案，避免教师改名后多处数据不一致。

**问：如何保证不修改课程目录？**

答：Controller 只提供 GET，Service 标记为只读事务，前端也没有编辑入口。

**问：10 秒预算在哪里体现？**

答：status 接口把外部系统约束作为元数据展示。真实接入时会在适配器客户端增加 10 秒超时和降级；课程版不假装已经发生网络调用。

## 及格重点

最重要的是讲清 Course 与 CourseOffering 的区别，以及“旧系统不可用时用只读适配模拟、但不伪造真实连接”。
