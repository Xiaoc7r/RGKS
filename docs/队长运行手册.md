# 队长运行手册（Windows 答辩版）

这份手册只解决三件事：在这台电脑上稳定启动、知道该用哪个账号、出现问题时能快速恢复。第一次请完整走一遍，正式答辩前再走一次“30 秒检查”。

## 最推荐：双击启动

1. 确认电脑已安装 **JDK 21、Maven 3.9+、Node.js 20+**。
2. 在项目根目录双击 `启动项目.cmd`。
3. 会打开两个命令窗口：`RGKS Backend` 和 `RGKS Frontend`。不要关闭它们。
4. 大约 10 秒后浏览器自动打开 `http://localhost:5173`。
5. 答辩结束后双击 `停止项目.cmd`。

启动脚本默认使用 H2 内存数据库，不需要 Docker、不需要安装 MySQL。每次停止后重新启动，数据都会恢复到标准演示状态，这是答辩最稳定的运行方式。

## 三个演示账号

| 身份 | 账号 | 密码 | 主要演示 |
|---|---|---|---|
| 学生 | `student1` | `Student123!` | 课程目录、4+2 选课、成绩单 |
| 教师 | `professor1` | `Professor123!` | 任课选择、学生名单、成绩录入 |
| 注册管理员 | `registrar` | `Registrar123!` | 人员档案、关选课、计费重试 |

建议用三个浏览器标签页分别登录三个角色。账号信息保存在 `sessionStorage`，同一标签页刷新不会掉线，关闭标签页后自动清除。

## 正式答辩推荐顺序

1. 管理员：展示人员档案与课程目录，暂时不要关闭选课。
2. 教师：选择一门无人任教课程，展示冲突/资格检查，再查看已有课程名单。
3. 学生：选择 4 门主选和 2 门备选并提交。
4. 教师：展示上学期已结束课程的成绩录入。
5. 学生：展示成绩单与 GPA。
6. 管理员：最后执行关闭选课，展示取消课程、冻结课表和计费。
7. 管理员：点一次“模拟失败”，再点“重试成功”。

关闭选课必须放最后，因为关闭后教师不能再调整任课，学生也不能再修改课表。如果顺序点乱，停止并重新运行项目即可恢复。

## 命令行启动（脚本失效时）

后端窗口：

```powershell
cd backend
mvn spring-boot:run -Dspring-boot.run.profiles=demo
```

前端窗口：

```powershell
cd frontend
npm install
npm run dev
```

看到后端日志出现 `Started CourseRegistrationApplication`，前端出现 `Local: http://localhost:5173/`，就说明启动成功。

## 30 秒检查

正式答辩前双击 `检查项目.cmd`。成功标准：

- 后端显示 `Tests run: 7, Failures: 0, Errors: 0`。
- 前端显示 `built in ...`，并生成 `frontend/dist`。
- 双击启动后，`http://localhost:8080/actuator/health` 返回 `{"status":"UP"}`。
- 浏览器能用 `student1` 登录。

## 常见故障

### 端口被占用

症状：后端提示 8080 已占用，或前端自动换到 5174。先双击 `停止项目.cmd`，再打开任务管理器确认旧的 Java/Node 开发进程已停止，然后重新启动。

### `java`、`mvn` 或 `npm` 不是命令

说明环境变量未配置。重新安装对应工具并勾选加入 PATH，关闭所有命令窗口后再试。版本检查：

```powershell
java -version
mvn -version
node -v
npm -v
```

### 页面能打开但登录失败

先访问 `http://localhost:8080/actuator/health`。若打不开，查看 `RGKS Backend` 窗口最下面的错误；若能打开，确认演示密码大小写和感叹号完全正确。

### 数据已经被关选课弄乱

答辩模式用的是内存数据库。关闭两个运行窗口，再双击 `启动项目.cmd`，标准数据会自动重建，不需要手工删库。

## MySQL 模式（报告展示用，不建议现场使用）

如果老师要求展示 MySQL，可先启动 Docker Desktop，再执行：

```powershell
docker compose up -d mysql
cd backend
mvn spring-boot:run
```

前端仍执行 `npm run dev`。MySQL 模式的数据会持久化，端口为 3307；答辩现场优先使用 H2 演示模式。
